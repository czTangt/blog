基础知识

命令行方式

gcc 编译链接

gcc 除了可以编译链接 c 语言后，还可以直接编译链接汇编代码。如果用汇编代码，一般是用不到 std 库和 os 共享库的，可以用 -nostdlib 和 -static 参数来处理，如下

1

gcc -nostdlib -static exit.s -o exit.elf  # .elf可以不加

这样就能避免导入 std 库，也不用有 main 函数，同时采用静态链接的当时不会再引用动态库。

strace 显示执行过程

这里使用 strace 来运行程序，会显示程序进行的每一个步骤。这里就发现，最简单的 c 程序也需要大量使用到动态链接库，而这里题目要求编写最为简单的汇编代码，就是不让使用动态链接。所以这里就是可以使用 strace 来查看程序的情况，以便解决问题。

objdump 查看文件

objdump 显示二进制程序的所有模块（hd file 可以以十六进制查看文件内容）。

1
2
3

objdump -M intel -d exit.elf
# -M 指定指令集格式
# -d 反汇编全部
objcopy 提取字节码

objcopy 提取二进制程序模块，它可以将二进制程序中的模块汇编代码单独提取出来，转化为字节码存储。

1
2
3

objcopy --dump-section .text=exit.bin exit.elf
# --dump-section .text=exit.bin 指从输入文件中把.text节的内容提取出来保存到exit.bin中
# exit.elf 是输入文件

下面是汇编代码的指定需要包含的内容。

.global _start        	; 定义_start为全局标签，它是程序的入口

    add rsi,1
    jmp loop
done:
    ret

push rbp

    sub rsp,0x100
    mov rbx,-1					;都是从-1开始，以便后面先增长，再其余步骤操作
loop1:
    add rbx,1
    cmp rbx,rsi
    je lp1
    mov cl,byte ptr [rdi+rbx] 	;这里对于byte操作，需要对应位数的寄存器
    add byte ptr [rsp+rcx], 1	;这里应该是stack_base减去的，但是这里是加，巧妙利用rsp和ebp的位置关系来操作
    jmp loop1
lp1:
    mov rbx,-1
    xor rcx,rcx
    xor rdx,rdx
loop2:
    add rbx,1
    cmp rbx,0x100
    je lp2
    cmp byte ptr [rsp+rbx], cl
    jle loop2
    mov cl,byte ptr [rsp+rbx]
    mov rdx,rbx
    jmp loop2
lp2:
    mov rax,rdx
    mov rsp,rbp
    pop rbp
    ret

level 7

很惊奇，直接 call (void)win() 调用函数就出了，一开始还想着劫持返回地址来跳转来着，看来是想麻烦了。

这里补充 gdb 中可以调用函数的约束

  1. 函数必须是可见的：在 GDB 中调用的函数必须是在当前调试的程序的可执行代码中可见的。如果函数是在外部库或未加载的模块中定义的，GDB 将无法直接调用它
  2. 函数必须是没有副作用的：GDB 中的函数调用是在调试过程中进行的，调用函数可能会影响程序状态，包括改变变量的值等。因此，最好只在调试过程中调用没有副作用的函数，以避免意外行为
